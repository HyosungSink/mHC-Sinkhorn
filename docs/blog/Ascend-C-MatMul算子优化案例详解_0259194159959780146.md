# Ascend C 入门（五）：矩阵乘法算子优化案例详解

在前几篇文章中，我们了解了 Ascend C 的基础知识、编译与运行流程。本篇将进入实战，学习如何用 Ascend C 编写一个 **矩阵乘法（Matrix Multiplication, GEMM）算子**，并逐步进行优化。

矩阵乘法是 AI 算法中最常见的计算核心之一（如深度学习中的卷积、全连接层都依赖矩阵乘法）。因此，通过矩阵乘法算子的实现和优化，可以直观理解 **Ascend C 的并行计算思想与内存优化方法**。

---

## 1. 问题定义

假设有两个矩阵：

* 矩阵 A，形状 `(M × K)`
* 矩阵 B，形状 `(K × N)`
* 结果矩阵 C，形状 `(M × N)`

数学公式为：

C[i][j]=∑k=0K−1A[i][k]×B[k][j]C[i][j] = \\sum\_{k=0}^{K-1} A[i][k] \\times B[k][j]**C**[**i**]**[**j**]**=**k**=**0**∑**K**−**1****A**[**i**]**[**k**]**×**B**[**k**]**[**j**]**目标：使用 Ascend C 在 AI Core 上实现这一计算。

---

## 2. 基础实现（Naive Version）

首先写一个最简单的实现，不考虑优化：


```
#include "kernel_operator.h"

// 简单矩阵乘法核函数
__aicore__ inline void MatMulNaive(const float* A, const float* B, float* C,
                                   int M, int N, int K) {
    for (int i = 0; i < M; ++i) {
        for (int j = 0; j < N; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < K; ++k) {
                sum += A[i * K + k] * B[k * N + j];
            }
            C[i * N + j] = sum;
        }
    }
}

// 内核入口
extern "C" __global__ __aicore__ void MatMulNaiveEntry(const float* A,
                                                       const float* B,
                                                       float* C,
                                                       int M, int N, int K) {
    MatMulNaive(A, B, C, M, N, K);
}
```


* **优点**：容易理解，结构清晰。
* **缺点**：没有利用并行计算和向量化，速度较慢。

---

## 3. 基于 Block 的并行优化

Ascend C 提供 **并行线程（block、thread）** 执行机制。
我们可以让每个 **线程块（block）负责计算 C 的一个子块**，从而提升并行度。


```
__aicore__ inline void MatMulBlock(const float* A, const float* B, float* C,
                                   int M, int N, int K) {
    int row = GetBlockIdxY();  // block 在 Y 维度的位置
    int col = GetBlockIdxX();  // block 在 X 维度的位置

    if (row < M && col < N) {
        float sum = 0.0f;
        for (int k = 0; k < K; ++k) {
            sum += A[row * K + k] * B[k * N + col];
        }
        C[row * N + col] = sum;
    }
}

extern "C" __global__ __aicore__ void MatMulBlockEntry(const float* A,
                                                       const float* B,
                                                       float* C,
                                                       int M, int N, int K) {
    MatMulBlock(A, B, C, M, N, K);
}
```


* 每个线程块负责计算一个元素 `C[row][col]`。
* 提高了并行度，但仍然存在 **访存效率低** 的问题。

---

## 4. 使用共享内存（Shared Memory）优化

矩阵乘法的瓶颈通常在 **内存访问**，尤其是重复访问 A 和 B。
解决方法：使用 **共享内存** 将矩阵块缓存起来。

思路：

1. 把 A 的一行和 B 的一列加载到共享内存。
2. 每个线程使用共享内存中的数据计算。
3. 避免重复访问全局内存。

代码示例：


```
#define BLOCK_SIZE 16

__aicore__ inline void MatMulShared(const float* A, const float* B, float* C,
                                    int M, int N, int K) {
    __shared__ float sharedA[BLOCK_SIZE][BLOCK_SIZE];
    __shared__ float sharedB[BLOCK_SIZE][BLOCK_SIZE];

    int row = GetThreadIdxY() + GetBlockIdxY() * BLOCK_SIZE;
    int col = GetThreadIdxX() + GetBlockIdxX() * BLOCK_SIZE;

    float sum = 0.0f;

    for (int t = 0; t < (K + BLOCK_SIZE - 1) / BLOCK_SIZE; ++t) {
        // 加载 A 和 B 的子块到共享内存
        if (row < M && (t * BLOCK_SIZE + GetThreadIdxX()) < K) {
            sharedA[GetThreadIdxY()][GetThreadIdxX()] =
                A[row * K + t * BLOCK_SIZE + GetThreadIdxX()];
        } else {
            sharedA[GetThreadIdxY()][GetThreadIdxX()] = 0.0f;
        }

        if (col < N && (t * BLOCK_SIZE + GetThreadIdxY()) < K) {
            sharedB[GetThreadIdxY()][GetThreadIdxX()] =
                B[(t * BLOCK_SIZE + GetThreadIdxY()) * N + col];
        } else {
            sharedB[GetThreadIdxY()][GetThreadIdxX()] = 0.0f;
        }

        __syncthreads();  // 确保数据加载完成

        // 计算子块的乘法
        for (int k = 0; k < BLOCK_SIZE; ++k) {
            sum += sharedA[GetThreadIdxY()][k] * sharedB[k][GetThreadIdxX()];
        }

        __syncthreads();
    }

    if (row < M && col < N) {
        C[row * N + col] = sum;
    }
}

extern "C" __global__ __aicore__ void MatMulSharedEntry(const float* A,
                                                        const float* B,
                                                        float* C,
                                                        int M, int N, int K) {
    MatMulShared(A, B, C, M, N, K);
}
```


* **BLOCK\_SIZE**：决定一次加载的子块大小。
* **共享内存缓存**：显著减少了对全局内存的访问次数。
* **同步机制**：保证每个线程都能正确使用共享内存。

---

## 5. 优化思考

1. **内存复用**
   在实际模型中，矩阵往往很大，利用共享内存能极大减少数据传输开销。
2. **向量化指令**
   Ascend C 支持向量化操作，例如 `DataCopy` 和 `Mmad`，可以进一步加速。
3. **流水线并行**
   可以让数据加载与计算并行，减少等待时间。
4. **调优参数**
   `BLOCK_SIZE` 需要根据硬件和矩阵规模调优。

---

## 6. 小结

通过这个案例，我们逐步实现了 **矩阵乘法算子**，并从 **最简单实现** 到 **共享内存优化版本**，展示了 Ascend C 的算子优化思路。

* **Naive 版本**：正确但慢。
* **Block 并行版本**：提升了并行度。
* **共享内存优化版本**：显著减少了内存访问，提高性能。

矩阵乘法是 Ascend 算子开发中最经典的例子。理解并掌握它的优化过程，对后续学习卷积算子、注意力机制等复杂算子有很大帮助。
