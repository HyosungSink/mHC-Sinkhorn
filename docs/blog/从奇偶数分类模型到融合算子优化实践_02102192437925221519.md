## 背景

## 基础模型实现

核心思路很直接：输入一个整数，取最后一位数字（0~9），通过 embedding + 两层全连接网络，输出该数的奇偶性分类结果。

```python
import torch
import torch.nn as nn

class OddEvenClassifier(nn.Module):
    def __init__(self):
        super(OddEvenClassifier, self).__init__()
        # 输入是最后一位数字 (0~9)，Embedding 维度 256
        self.embedding = nn.Embedding(10, 256)
        self.fc1 = nn.Linear(256, 512)
        self.fc2 = nn.Linear(512, 2)
        self.relu = nn.ReLU()
        # self.prelu = nn.PReLU()  # 可以替换尝试

    def forward(self, x):
        # 取最后一位数字
        x = x % 10
        x = self.embedding(x)       # [batch, 256]
        x = self.relu(self.fc1(x))  # [batch, 512]
        x = self.fc2(x)             # [batch, 2]
        return x
在这个模型中，计算热点主要集中在：

融合算子设计思路
为了减少算子间的调用开销与中间结果存取开销，我尝试编写一个 融合算子 来替代 linear -> relu -> linear 的计算模式。

目标
实现 matmul + relu 的融合计算。

难点
Tiling 策略需要兼顾 M/N/K 的多样性，避免固定分块带来的不适配。

ReLU 的实现需要在 local tensor 上高效进行计算。

融合算子实现
以下展示了算子关键部分的设计思路。

Tiling 配置
通过 MultiCoreMatmulTiling 自动选择合适的分块策略，避免手动硬编码。

复制代码
int32_t baseM = std::min(128, M);
int32_t baseN = std::min(128, N);

int32_t singleCoreN = std::min(640, N);

cubeTiling.SetShape(M, N, K);

内核执行流程
Matmul 计算：完成 A × B + bias，结果放入 reluOutLocal。

ReLU 激活：对 reluOutLocal 执行逐元素 max(x, 0)。

CopyOut：将 ReLU 后结果写回全局内存，进入下一个算子。

cpp
复制代码
template 
__aicore__ inline void MmremmKernel::ReluCompute()
{
    uint32_t elementNum = tiling.baseM * tiling.baseN;

    AscendC::LocalTensor tmp = tmpQueue_.AllocTensor();
    AscendC::Duplicate(tmp, (cType)0, elementNum);

    // ReLU: max(x, 0)
    AscendC::Min(tmp, reluOutLocal, tmp, elementNum);
    AscendC::Sub(reluOutLocal, reluOutLocal, tmp, elementNum);

    tmpQueue_.FreeTensor(tmp);
}
```
