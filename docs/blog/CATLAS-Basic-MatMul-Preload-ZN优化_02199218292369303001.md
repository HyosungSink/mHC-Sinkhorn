一、CATLAS 算子与 MatMul Preload ZN 优化背景 CATLAS 是昇腾面向 Ascend C 推出的底层算子加速开发库，封装 AI Core 流水线、多级缓存、数据预取、分块调度通用接口，大幅简化矩阵乘等高计算密度算子开发。矩阵乘 MatMul 是大模型 Transformer、CNN 网络核心计算算子，标准 MatMul 分为左矩阵 A、右矩阵 B、输出矩阵 C，硬件存储划分为 GM 全局内存、L0A/L0B 输入缓存、L1 输出缓存、MTE 矩阵计算单元。 原生 Basic MatMul 存在明显访存瓶颈：B 矩阵权重（ZN 块）反复从 GM 加载至 L0B，每一轮分块计算都触发 GM-L0 数据搬运，DDR 访存延迟成为算力瓶颈。Preload ZN 是 CATLAS 提供的权重预加载优化机制，核心思路为：训练 / 推理中权重矩阵 B 固定不变时，在计算循环启动前一次性将完整 ZN 权重分块预加载至 L0B 缓存，循环内复用缓存数据，消除每轮重复 GM 读取，掩盖数据传输延迟，提升 MTE 计算单元利用率。 ZN 代表 B 矩阵沿 N 维度分块，Preload ZN 适配固定权重场景，如 LLM 线性层、全连接层 MatMul，配合 CATLAS 流水线调度实现计算与数据搬运并行。本文基于 CATLAS 接口实现带 Preload ZN 的 Basic MatMul 算子，讲解分块逻辑、预加载调度、流水线同步、编译部署全流程。 二、Preload ZN 核心优化原理 缓存分区规划 AI Core L0B 缓存专门存放预加载的 ZN 权重分块，计算循环全程锁定缓存不释放；输入 A 矩阵分块采用流式逐块加载，实现 A 加载与 MTE 矩阵乘计算并行。 一次预加载、多轮复用 常规 MatMul 每一轮 K 维度循环都重新读取 B 分块；Preload ZN 仅在最外层循环执行一次 CopyIn 将 ZN 块存入 L0B，内层 K、M 循环直接复用片上缓存，GM 访存流量降低 60% 以上。 流水线同步机制 CATLAS Pipe 自动管理预加载与计算依赖，预加载未完成时阻塞 MTE 计算，数据就绪后自动启动矩阵乘，无需手动插入同步指令，降低开发复杂度。 分块约束条件 ZN 块总字节数不能超过 L0B 最大容量；权重 B 维度 N 需为分块对齐长度（16/32/64），满足昇腾向量单元 16 字节对齐要求，避免非对齐访存停顿。 三、基于 CATLAS 的 Preload ZN MatMul 完整代码 3.1 算子内核 matmulpreloadzn.cpp #include "catlas/catlas.h" using namespace AscendC; // 分块超参，适配L0B缓存容量 constexpr int BLOCKM = 128; constexpr int BLOCKK = 64; constexpr int BLOCK_N = 256; // ZN分块尺寸 aicore void MatMulPreloadZNKernel( GMADDR gmA, GMADDR gmB, GMADDR gmC, int M, int K, int N) { Pipe pipe; // L0B缓存用于预加载ZN权重块，全程复用 LocalTensor ZNB = pipe.AllocTensor(BLOCKK * BLOCKN, TPosition::L0B); // L0A流式存放A矩阵M*K分块，每轮刷新 LocalTensor tileA = pipe.AllocTensor(BLOCKM * BLOCKK, TPosition::L0A); // L1缓存存放矩阵乘中间结果 LocalTensor tileC = pipe.AllocTensor(BLOCKM * BLOCK_N, TPosition::L1);// 1. Preload ZN核心：外层N循环一次性预加载B的ZN块至L0B CopyIn(ZN_B, gm_B, BLOCK_K * BLOCK_N);  // 2. M维度分块循环，复用已预加载的ZN_B权重 for (int m_start = 0; m_start < M; m_start += BLOCK_M) {     int cur_m = min(BLOCK_M, M - m_start);     GM_ADDR gm_A_tile = gm_A + m_start * K * sizeof(half);     CopyIn(tile_A, gm_A_tile, cur_m * BLOCK_K);      // 3. CATLAS封装矩阵乘接口，复用L0B预加载权重     CatlasMatMul(tile_C, tile_A, ZN_B, cur_m, BLOCK_K, BLOCK_N);      // 4. 计算结果写回全局内存     GM_ADDR gm_C_tile = gm_C + m_start * N * sizeof(half);     CopyOut(gm_C_tile, tile_C, cur_m * BLOCK_N); } } // 内核实例化FP16模板 template aicore void MatMulPreloadZNKernel( GMADDR, GMADDR, GMADDR, int, int, int); 关键优化点：ZNB分配在 L0B 缓存，在循环外部仅执行一次 CopyIn 完成 Preload ZN；内层 M 循环仅流式加载 A 矩阵，反复复用权重缓存，消除重复读取 B 矩阵的 DDR 开销。CatlasMatMul为 CATLAS 封装 MTE 矩阵乘原语，自动完成流水线同步、向量化计算。 3.2 Tiling 分块调度逻辑 tiling.h #ifndef MATMULTILINGH #define MATMULTILINGH #include "tiling/tiling_api.h" uint64t MatMulPreloadZNTiling(TilingData* tiling, uint64t M, uint64t K, uint64t N, uint32t dtype) { uint32t elemsize = 2; // FP16 half 2字节 uint64t l0bmaxelem = 256 * 1024 / elemsize; // 约束ZN分块不超出L0B缓存上限 tiling->blockn = min(256, N); tiling->blockk = 64; tiling->blockm = 128; tiling->preloadznenable = 1; // 标记启用ZN预加载 return 0; } #endif Tiling 层标记preloadznenable，使上层调度识别预加载逻辑，分配专属 L0B 缓存空间，防止其他算子抢占权重缓存。 3.3 算子原型 matmul.opproto proto op MatMulPreloadZN { input A: tensor<>; input B: tensor<>; output C: tensor<*>; supportdtype: float16;
