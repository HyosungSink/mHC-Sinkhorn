# 开发CANN自定义算子

## 一、 引言：为什么需要自定义算子？

随着深度学习模型日益复杂（如Transformer、Diffusion等），框架原生的算子库有时无法满足特定模型或创新结构的计算需求。这时，我们需要通过自定义算子（Custom Operator）来实现：

1. ******高性能计算**：针对特定硬件（如Ascend NPU）和特定计算模式进行深度优化，发挥硬件极致性能。
2. ******功能扩展**：实现框架（如TensorFlow， PyTorch）尚未支持的前沿操作。
3. ******算子融合**：将多个小算子融合成一个大算子，减少内存读写开销，显著提升性能。

华为CANN（Compute Architecture for Neural Networks）为昇腾（Ascend）AI处理器提供了强大的编程能力，其中TBE（Tensor Boost Engine）是其自定义算子开发的核心工具链。

---

## 二、 开发环境与基础概念

### 1. 环境准备

* ******硬件**：Ascend 310/910 AI处理器
* ******软件**：CANN Toolkit（需安装并配置好环境变量）
* ******Python**: 推荐3.7+
* ******开发工具**：MindStudio（提供图形化调试和性能分析工具）或纯文本编辑器

### 2. 核心概念

* ******TBE (Tensor Boost Engine)**： 提供了一套基于Python的API，用于在昇腾AI处理器上定义和编译自定义算子。
* ******DSL (Domain Specific Language)**： 一种高级的、类似NumPy的编写方式，开发效率高，易于理解。
* ******AutoTune**： 自动调优工具，能自动为算子尝试多种编译参数（如tiling策略、循环优化等），并选择性能最优的配置，极大降低了手动调优的门槛。
* ******计算流程**： 自定义算子的核心是描述如何从输入张量（Tensor）计算出输出张量，通常包括数据搬运（Copy-in/Copy-out）和计算核（Compute Core）。

---

## 三、 DSL开发模式实战：以GeLU算子为例

DSL模式简单直观，非常适合初学者和快速原型开发。我们以实现一个Gaussian Error Linear Unit (GeLU) 激活函数为例。

GeLU公式：`gelu(x) = 0.5 * x * (1 + tanh( sqrt(2/pi) * (x + 0.044715 * x^3)) )`

### 1. 算子定义文件（\*.py）

```
# gelu_custom.py

import te.lang.cce
from te import tvm
from topi import generic
import impl

def gelu_compute(input_x, output_y):
    """
    定义GELU的计算过程。
    """
    # 定义常量
    sqrt_2_over_pi = impl.constant_value(0.7978845834732056, dtype=input_x.dtype)
    constant_one = impl.constant_value(1.0, dtype=input_x.dtype)
    constant_half = impl.constant_value(0.5, dtype=input_x.dtype)
    coeff = impl.constant_value(0.044715, dtype=input_x.dtype)

    # 使用TBE DSL API描述计算图
    x_pow3 = te.lang.cce.vmul(input_x, te.lang.cce.vmul(input_x, input_x)) # x^3
    inner_term = te.lang.cce.vmul(coeff, x_pow3)
    inner_term = te.lang.cce.vadd(input_x, inner_term)
    inner_term = te.lang.cce.vmul(sqrt_2_over_pi, inner_term)
    tanh_value = te.lang.cce.vtanh(inner_term)
    added = te.lang.cce.vadd(tanh_value, constant_one)
    multiplied = te.lang.cce.vmul(input_x, added)
    result = te.lang.cce.vmul(constant_half, multiplied)

    # 将计算结果赋值给输出张量
    with impl.for_range(0, input_x.shape[0]) as i:
        with impl.for_range(0, input_x.shape[1]) as j:
            output_y[i, j] = result[i, j]

def gelu_schedule(shape, dtype):
    """
    定义一个基础的调度（Schedule），决定如何将计算映射到硬件资源上。
    对于简单算子，可以使用默认调度。
    """
    # 对于DSL模式，schedule可以非常简单，甚至为空，编译器会自动调度。
    # 此处我们创建一个默认的schedule。
    sch = impl.tvm.create_schedule([output_y.op for output_y in ...]) # 伪代码，实际需根据输出构建
    return sch

# 注册算子信息
@impl.op_info_register("GeluCustom")
def gelu_op_info():
    """
    注册算子的输入输出信息和属性。
    """
    op_info = impl.OpInfo()
    op_info.add_input(impl.TensorDesc("x", impl.Format.FRACTAL_NZ, impl.Dtype.FLOAT16))
    op_info.add_output(impl.TensorDesc("y", impl.Format.FRACTAL_NZ, impl.Dtype.FLOAT16))
    return op_info
```

```
[GeluCustom]
op_pattern = dynamicFormat
input0.name = x
input0.dtype = float16
input0.format = ND,FRACTAL_NZ # 支持多种格式
output0.name = y
output0.dtype = float16
output0.format = ND,FRACTAL_NZ
```

### 3. 编译与部署

使用CANN提供的`fmk.py`或`msopgen`工具将Python代码编译成昇腾AI处理器支持的离线模型文件（\*.o）。

```
# 使用fmk.py进行编译
python ${CANN_HOME}/fmk.py --op=gelu_custom.py --impl_path=./ --output=./gelu_op
```

编译成功后，会生成`.o`和`.json`文件，即可在AscendCL应用程序中加载和调用。

## 四、 AutoTune自动调优：让编译器为你优化

对于复杂算子，手动调优（TIK模式）极其困难。AutoTune工具可以自动探索最优配置。

### 1. 启用AutoTune

只需在编译时增加`--enable_autotune`参数即可。

```
python ${CANN_HOME}/fmk.py --op=gelu_custom.py --impl_path=./ --output=./gelu_op --enable_autotune
```

### 2. AutoTune工作原理

1. ******策略空间构建**：编译器根据算子计算描述，自动构建一个包含多种可能调度策略（如循环分块大小、向量化、双缓冲等）的搜索空间。
2. ******性能评估**：AutoTune会在模型或模拟器上编译和运行这些不同策略的算子实现，并采集其性能数据。
3. ******选择最优解**：比较所有测试策略的性能，最终选择耗时最短的那个策略作为该算子的最终实现。

### 3. 实践建议

* ******适用场景**：计算逻辑复杂、包含大量循环和矩阵运算的算子。
* ******耗时**：AutoTune过程可能较长，适合在模型部署前的优化阶段使用。
* ******结合使用**：通常先用DSL快速实现功能，再开启AutoTune进行性能优化。

## 五、 性能调试与优化技巧

### 1. 常用工具

* ******Profiling（Ascend Profiler）**： 通过`prof.sh`工具或MindStudio界面抓取运行数据，分析算子的执行时间、AI Core利用率、内存带宽等指标，定位性能瓶颈。
* ******msprof**： 命令行性能分析工具，可以生成可视化时间线。

### 2. 常见优化点

1. ******数据格式**： 使用`FRACTAL_NZ`等硬件友好的格式，相比于`ND`格式能极大提升矩阵运算效率。
2. ******内存搬运**： 尽量减少`Copy-in/Copy-out`次数，利用AI Core上的缓冲区（Local RAM）。
3. ******算子融合**： 将多个element-wise操作（如Add, Relu, Scale）融合成一个算子，减少内核启动开销和内存访问。
4. ******流水线优化**： 使用`double_buffer`等调度原语实现计算与数据搬运的并行。
5. ******向量化指令**： 对于循环，尽量使用`vectorize`调度，使编译器生成向量化指令。
