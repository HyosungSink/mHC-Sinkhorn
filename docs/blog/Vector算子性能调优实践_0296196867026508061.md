## 一、背景介绍

在昇腾 AI 芯片上开发算子时，硬件行为的不可见性给性能调优带来挑战。例如，Vector 计算单元与数据搬运单元（MTE）的资源冲突、指令流水线阻塞等问题，难以通过代码静态分析发现。

昇腾提供的仿真工具链（包括 CAModel、Gtkwave 等）可模拟 AI Core 的执行过程，可视化指令流与数据流，帮助开发者定位性能瓶颈。本文以一个简单的 Vector 加法算子为例，介绍如何利用仿真工具进行性能调优，提升算子运行效率。

## 二、环境准备

### 1.软件环境：

CANN 7.0 仿真工具包（含 CAModel）

Gtkwave 3.3.115（波形可视化工具）

Python 3.8（测试脚本运行）

### 2.工具安装：

```
# 安装仿真工具
sudo apt install ascend-simulator-7.0.0
# 安装Gtkwave
sudo apt install gtkwave
# 配置仿真环境变量
export SIMULATOR_PATH=/usr/local/Ascend/simulator
```

## 三、实操步骤

### 1.算子代码编写

实现一个简单的 Vector 加法算子（C = A + B），初始版本使用循环搬运小粒度数据：

```
// 初始版本（低效）
__global__ __aicore__ void VecAddKernel(GM_ADDR float* A, GM_ADDR float* B, GM_ADDR float* C, int len) {
    for (int i = 0; i < len; i++) {
        float a, b;
        DataCopy(&a, A + i, 1);  // 单次搬运1个元素（小粒度）
        DataCopy(&b, B + i, 1);
        C[i] = a + b;
    }
}
```

### 2.仿真文件准备

创建sim目录，包含：

vec_add.json：核启动参数（blockDim=1，kernelName="VecAddKernel"）

run_sim.py：生成测试数据、启动仿真并比对结果

run_sim.sh：仿真启动脚本（设置环境变量）

### 3.执行仿真与波形分析

```
# 编译算子
ccec -c vec_add.cce -o vec_add.o
# 执行仿真
cd sim && bash run_sim.sh
# 查看波形
gtkwave model/core0_wave.vcd
```

### 4.性能瓶颈定位

从波形图发现：MTE2（数据搬入）与 MTE3（数据搬出）频繁切换，导致带宽利用率仅 30%；Vector 单元存在大量空闲时间。

### 5.优化方案实施

改用批量数据搬运（一次搬运 64 个元素），减少 MTE 切换次数：

```
// 优化版本（高效）
__global__ __aicore__ void VecAddKernel(GM_ADDR float* A, GM_ADDR float* B, GM_ADDR float* C, int len) {
    LocalTensor<float> localA(64), localB(64), localC(64);
    for (int i = 0; i < len; i += 64) {
        DataCopy(localA, A + i, 64);  // 批量搬运
        DataCopy(localB, B + i, 64);
        AscendC::Add(localA, localB, localC);  // Vector批量计算
        DataCopy(C + i, localC, 64);
    }
}
```

## 四、关键代码解析

### 1.仿真配置文件

vec_add.json定义核启动参数，确保仿真环境正确加载算子：

```
{
    "blockDim": 1,
    "kernelName": "VecAddKernel",
    "magic": "RT_DEV_BINARY_MAGIC_ELF",
    "params": [
        {"name": "A", "type": "float*", "direction": "in"},
        {"name": "B", "type": "float*", "direction": "in"},
        {"name": "C", "type": "float*", "direction": "out"},
        {"name": "len", "type": "int", "value": 1024}
    ]
}
```

### 2.测试脚本核心逻辑

run_sim.py生成随机数据并启动仿真，验证结果正确性：

```
import numpy as np
from ascend_sim import Simulator

# 生成测试数据
A = np.random.rand(1024).astype(np.float32)
B = np.random.rand(1024).astype(np.float32)
C_expected = A + B

# 启动仿真
sim = Simulator(kernel_path="../vec_add.o", config_path="vec_add.json")
sim.set_input("A", A)
sim.set_input("B", B)
sim.run()

# 比对结果
C_actual = sim.get_output("C")
assert np.allclose(C_actual, C_expected, atol=1e-5)
```

### 3.优化前后波形对比

优化前：MTE2 与 MTE3 交替执行，Vector 单元等待时间占比 60%。

优化后：MTE2 批量搬入→Vector 批量计算→MTE3 批量搬出，流水线连续执行，Vector 单元利用率提升至 95%。
