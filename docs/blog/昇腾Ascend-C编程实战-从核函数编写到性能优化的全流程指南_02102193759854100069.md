# 1 引言：为什么选择Ascend C？

2023年5月，华为在昇腾AI开发者峰会上正式发布了​​Ascend C编程语言​​，这是CANN（Compute Architecture for Neural Networks）针对算子开发场景推出的专用语言。与CUDA为GPU编程类似，Ascend C允许开发者充分发挥昇腾AI处理器的强大算力，实现高性能的AI计算。

Ascend C原生支持C/C++编程规范，通过多层接口抽象、并行编程范式、孪生调试等关键技术，​​极大提高了算子的开发效率​​，帮助AI开发者低成本完成算子开发和模型调优部署。

本文将带您全面了解Ascend C的核心概念、编程模型和实战技巧，从基础架构到高级优化，助您快速掌握这一强大的编程语言。

## 2 昇腾AI硬件架构基础

### 2.1 异构计算架构

在基于CPU+NPU的异构计算架构中，NPU与CPU通过PCIe总线连接在一起协同工作：

- ​​CPU​​：负责整个操作系统运行，管理各类资源并进行复杂的逻辑控制
- ​​NPU​​：主要负责并行计算任务，可以看作是CPU的协处理器
CPU所在位置称为​​主机端（host）​​，而NPU所在位置称为​​设备端（device）​​。

### 2.2 昇腾AI处理器核心组成

昇腾AI处理器最核心的部件是​​AI Core​​，它是神经网络加速的计算核心。每个AI Core包含三个基本计算单元：

- ​​矩阵计算单元（Cube Unit）​​：负责矩阵计算操作
- ​​向量计算单元（Vector Unit）​​：负责向量计算操作
- ​​标量计算单元（Scalar Unit）​​：负责标量计算操作
AI Core内部还包含​​本地内存（Local Memory）​​和​​数据搬运单元（DMA）​​。Local Memory因为靠近计算单元，带宽非常高但容量较小（通常几百K到1M），而DMA搬运单元负责在Global Memory和Local Memory之间搬运数据。

## 3 Ascend C核心编程概念

### 3.1 核函数（Kernel Function）

核函数是Ascend C算子设备侧的入口，是在设备端AI Core上执行的代码。核函数需要按照特定规则编写：

```
extern "C" __global__ __aicore__ void add_custom(GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    KernelAdd op;
    op.Init(x, y, z);
    op.Process();
}

```

其中`__global__`函数类型限定符标识这是一个核函数，`__aicore__`函数类型限定符标识该核函数在设备端AI Core上执行。

### 3.2 编程范式：流水线并行

Ascend C采用​​流水线式的编程范式​​，把算子核内的处理程序分成多个流水任务（Stage），通过队列（Queue）完成任务间通信和同步，并通过统一的内存管理模块（Pipe）管理任务间通信内存。

矢量编程范式把算子的实现流程分为3个基本任务：

- ​​CopyIn​​：负责搬入操作，将数据从Global Memory搬运到Local Memory
- ​​Compute​​：负责矢量计算操作
- ​​CopyOut​​：负责搬出操作，将计算结果从Local Memory搬运回Global Memory

### 3.3 SPMD并行编程模式

Ascend C采用​​SPMD（单程序多数据）​​编程模式。多个AI Core共享相同的指令代码，每个核上的运行实例唯一的区别是block_idx（内置变量）不同。

通过block_idx区分不同的核，对Global Memory上的数据地址进行切分偏移，让每个核处理自己对应的那部分数据，实现多核并行计算的数据切分。

## 4 Ascend C API分类与功能

Ascend C提供了一系列类库API，主要分为以下几类：

- ​​计算类API​​：包括标量计算API、向量计算API、矩阵计算API，分别调用不同的计算单元执行计算功能
- ​​数据搬运API​​：如DataCopy接口，负责在Global Memory和Local Memory之间搬运数据
- ​​内存管理API​​：用于分配管理内存，如AllocTensor、FreeTensor接口
- ​​任务同步API​​：完成任务间的通信和同步，如EnQue、DeQue接口
Ascend C API的计算操作数都是Tensor类型：GlobalTensor和LocalTensor。

## 5 实战示例：编写Add算子

### 5.1 算子分析与设计

以简单的加法算子为例，其数学表达式为：z = x + y。

设计规格如下：

- 输入x：shape(8,2048), dtype: half, format: ND
- 输入y：shape(8,2048), dtype: half, format: ND
- 输出z：shape(8,2048), dtype: half, format: ND
- 核函数名称：add_custom

### 5.2 核函数实现

```
extern "C" __global__ __aicore__ void add_custom(GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    KernelAdd op;
    op.Init(x, y, z);
    op.Process();
}

```

### 5.3 算子类实现

```
class KernelAdd {
public:
    __aicore__ inline KernelAdd() {}
    
    // 初始化函数
    __aicore__ inline void Init(GM_ADDR x, GM_ADDR y, GM_ADDR z)
    {
        // 获取当前核心的数据起始地址偏移
        GM_ADDR xGmOffset = x + BLOCK_LENGTH * GetBlockIdx();
        GM_ADDR yGmOffset = y + BLOCK_LENGTH * GetBlockIdx();
        GM_ADDR zGmOffset = z + BLOCK_LENGTH * GetBlockIdx();
        
        xGm.SetGlobalBuffer((__gm__ half*)xGmOffset, BLOCK_LENGTH);
        yGm.SetGlobalBuffer((__gm__ half*)yGmOffset, BLOCK_LENGTH);
        zGm.SetGlobalBuffer((__gm__ half*)zGmOffset, BLOCK_LENGTH);
        
        // 通过pipe为queue分配内存
        pipe.InitBuffer(inQueueX, BUFFER_NUM, TILE_LENGTH * sizeof(half));
        pipe.InitBuffer(inQueueY, BUFFER_NUM, TILE_LENGTH * sizeof(half));
        pipe.InitBuffer(outQueueZ, BUFFER_NUM, TILE_LENGTH * sizeof(half));
    }
    
    // 核心处理函数
    __aicore__ inline void Process()
    {
        // 多个任务实现流水并行
        for (int32_t i = 0; i  xLocal = inQueueX.AllocTensor();
        LocalTensor yLocal = inQueueY.AllocTensor();
        
        DataCopy(xLocal, xGm[progress * TILE_LENGTH], TILE_LENGTH);
        DataCopy(yLocal, yGm[progress * TILE_LENGTH], TILE_LENGTH);
        
        inQueueX.EnQue(xLocal);
        inQueueY.EnQue(yLocal);
    }
    
    __aicore__ inline void Compute(int32_t progress)
    {
        LocalTensor xLocal = inQueueX.DeQue();
        LocalTensor yLocal = inQueueY.DeQue();
        LocalTensor zLocal = outQueueZ.AllocTensor();
        
        Add(zLocal, xLocal, yLocal, TILE_LENGTH);
        
        outQueueZ.EnQue(zLocal);
        inQueueX.FreeTensor(xLocal);
        inQueueY.FreeTensor(yLocal);
    }
    
    __aicore__ inline void CopyOut(int32_t progress)
    {
        LocalTensor zLocal = outQueueZ.DeQue();
        DataCopy(zGm[progress * TILE_LENGTH], zLocal, TILE_LENGTH);
        outQueueZ.FreeTensor(zLocal);
    }

private:
    TPipe pipe;
    TQue inQueueX, inQueueY;
    TQue outQueueZ;
    GlobalTensor xGm, yGm, zGm;
};

```

## 6 性能优化高级技巧

### 6.1 API使用优化

- ​​在算子kernel类外创建TPipe对象​​：触发类内Scalar编译优化，减少Scalar指令耗时。
- ​​使用TQueBind接口​​：对于纯搬运类算子，可以使用TQueBind接口实现VECIN和VECOUT内存复用，避免冗余vector计算。
- ​​SetMaskCount接口​​：开启Counter模式简化mask处理逻辑，减少代码量和Scalar计算量。

### 6.2 流水线优化

通过​​Double Buffer技术​​和​​异步指令执行​​，实现数据搬运和计算的并行处理，提高AI Core内部各单元的利用率。

```
// 使用Double Buffer优化后的Process函数
__aicore__ inline void Process()
{
    // 开启double buffer后循环次数需要乘以2
    constexpr int32_t loopCount = TILE_NUM * BUFFER_NUM;
    
    // 多个任务实现流水并行
    for (int32_t i = 0; i = 1) {
            Compute(i - 1);
        }
        if (i >= 2) {
            CopyOut(i - 2);
        }
    }
    // 处理最后两个任务
    Compute(loopCount - 1);
    CopyOut(loopCount - 2);
    CopyOut(loopCount - 1);
}

```

### 6.3 内存访问优化

- ​​合理使用Local Memory​​：尽量将频繁访问的数据保存在Local Memory中，减少Global Memory访问次数。
- ​​数据对齐​​：确保内存访问模式符合硬件对齐要求，提高存取效率。
- ​​合并内存访问​​：尽量实现连续、合并的内存访问模式，提高内存带宽利用率。
