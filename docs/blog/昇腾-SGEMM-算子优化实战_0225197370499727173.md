## 一、背景介绍 

在深度学习与科学计算中，矩阵乘法（GEMM）是核心算子，其性能直接影响整个系统的效率。昇腾 AI 芯片（如 Atlas 800T A2）通过异构计算架构（Cube 核与 Vector 核协同）提供强大算力，但原生算子在非对齐内存访问、缓存利用率等场景下性能受限。本文基于昇腾 CANN 平台，分享单精度矩阵乘（SGEMM）的优化实践，通过 Padding 对齐、双缓冲等技术提升算子性能。 

## 二、环境准备 

### 1.硬件环境：

Atlas 800T A2 训练卡（含 20 个计算 Group，每个 Group 含 1 个 AIC+2 个 AIV）。 

### 2.软件环境： 

CANN 7.0 及以上（提供昇腾算子开发工具链）； 

MindStudio 5.0（代码开发与调试）； 

msprof 性能分析工具（CANN 自带，用于瓶颈定位）。 

### 3.代码依赖：

昇腾开源算子库ascend-accelerate（含基础 GEMM 实现）。

## 三、实操步骤 

### 1. 基础 SGEMM 算子实现 

基于昇腾 CCE 编译器，编写基础 SGEMM 算子，实现C = αA×B + βC计算：

```
# 克隆开源算子库
git clone https://gitee.com/ascend/accelerate.git
cd accelerate/operators/gemm/sgemm

```

### 2. 非对齐内存访问优化（Padding） 

昇腾 GM 内存需 512B 对齐以最大化带宽，对输入矩阵进行 Padding 处理： 

计算对齐后的矩阵维度（如M_padding = ceil(M / 16) * 16，16 为 Float32 类型的 512B 对齐单位）； 

在 AIV 核中实现数据重排，将非对齐数据补 0 后存入对齐地址。 

### 3. 双缓冲优化 

通过 L1 Cache 双缓冲实现数据加载与计算并行： 

为矩阵 A、B 各分配两个 L1 缓冲区（L1_A_buf1/L1_A_buf2，L1_B_buf1/L1_B_buf2）； 

当 Cube 核计算当前缓冲区数据时，Vector 核异步加载下一批数据至另一缓冲区。 

### 4. 编译与部署

```
# 编译AIC和AIV算子
ccec -std=c++17 -c sgemm_mix.cce -o sgemm_aic.o --cce-aicore-arch=dav-c220-cube
ccec -std=c++17 -c sgemm_mix.cce -o sgemm_aiv.o --cce-aicore-arch=dav-c220-vec
# 链接生成算子二进制
ld.lld -Ttext=0 sgemm_aic.o sgemm_aiv.o -static -o sgemm_mix.o

```

### 1.性能测试：使用随机矩阵（256×256×256）测试，优化前后对比： 

未优化：280 GFLOPS，L2 Cache 命中率 65%； 

优化后：420 GFLOPS（提升 50%），L2 Cache 命中率 92%。 

### 2.工具验证：通过msprof分析流水图：

```
msprof op --application="./sgemm_test 256 256 256" --output=./prof

```

结果显示 Cube 核流水线连续无空闲，Vector 核与 Cube 核并行率达 90%。
